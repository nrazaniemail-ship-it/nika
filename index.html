اسکن هوشمند فاکتور و تکمیل خودکار فرم

عکس را با دوربین بگیر یا از گالری/PDF انتخاب کن. نیکا اطلاعات مشتری و مبالغ را استخراج و فرم را تکمیل می‌کند. بدون کلید API از OCR فارسی روی دستگاه استفاده می‌شود؛ با کلید API تحلیل هوشمند دقیق‌تر فعال است. قبل از ثبت، مبالغ و تاریخ را کنترل کن.

نکته امنیتی مهم

فایل پشتیبان شامل اطلاعات مالی مشتریان و ممکن است شامل تصویر فاکتورها باشد. آن را در فضای امن نگهداری کنید و برای دیگران ارسال نکنید. کلید API از پشتیبان حذف می‌شود. اطلاعات در این نسخه روی دستگاه ذخیره می‌شود و رمزنگاری سرتاسری یا همگام‌سازی ابری فعال نیست.
